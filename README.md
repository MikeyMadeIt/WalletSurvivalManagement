## Wallet Survival Management System

A VB.NET console-based financial management application designed to help users monitor their wallet balance, manage income and expenses, set budgets, track savings goals, and estimate how long their remaining money can last.

## Project Overview

The Wallet Survival Management System focuses on personal financial awareness and money management. It provides a simple console interface where users can record transactions, monitor spending habits, manage budgets, and evaluate their financial situation.

## Features

- Wallet Management: Manage wallet information and monitor available balance.
- Income Management: Record and manage sources of income.
- Expense Management: Record, categorize, and monitor expenses.
- Budget Management: Set spending limits and track budget usage.
- Savings Management: Create savings goals and monitor contributions.
- Transaction History: View and search recorded transactions.
- Financial Reports: Generate financial summaries and spending reports.
- Survival Analysis: Estimate how many days the remaining balance can support the user's expenses.
