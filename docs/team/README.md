
# Team Guidelines

Contains team assignments, development procedures, and collaboration guidelines.

## Development Branches

- `main` - Stable project structure and approved releases.
- `develop` - Integration branch for development.
- `dev/mikey`
- `dev/mapalo`
- `dev/lopez`
- `dev/tejada`
- `dev/felix`

## Development Guidelines

1. Work on your assigned development branch.
2. Follow the agreed project structure.
3. Use consistent VB.NET naming conventions.
4. Test changes before submitting them.
5. Use Pull Requests when integrating changes.
6. Do not directly modify another member's assigned module without coordination.
